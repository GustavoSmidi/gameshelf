# GameShelf

GameShelf is a full-stack web application designed to provide a centralized space for players to organize, track, rate, review, and share their gaming experiences.  The platform combines a personal game library with social, discovery, and statistical features, allowing users to manage their gaming activity and keep track of their experiences in one place. 

This project was developed as a portfolio project, covering the entire development process from UI/UX design and database modeling to backend, frontend, and cloud infrastructure. 

## Features

- Personal game library
- Game ratings
- Reviews
- User profiles
- Friends and social interactions
- Game discovery
- Personal gaming statistics
