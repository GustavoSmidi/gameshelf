# GameShelf

GameShelf is a full-stack web application designed to help players organize, track, rate, review, and share their gaming experiences. The project aims to combine a personal game library with social and discovery features, providing a centralized platform for managing gaming activity. Developed as a portfolio project, GameShelf covers the software development process, including UI/UX design, database modeling, backend and frontend development, and cloud infrastructure.

## Features

- Personal game library
- Game ratings and reviews
- User profiles
- Social interactions
- Game discovery
- Personal gaming statistics
- User authentication and account management
